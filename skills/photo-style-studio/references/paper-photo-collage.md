# Paper Photo Collage / 纸上摄影拼贴

## 目标与风格边界

将原片制作成暖纸上的混合媒介摄影作品：核心场景保持摄影细节，从外围逐渐过渡到水彩色块、干刷、少量线稿与纸面留白，配一小行文字。它不是 luminous-watercolor 的全图水彩化，也不是 geo-editorial 的原像素锁定叠图。

preservation=subject-faithful：保留主体身份、空间关系、轮廓、人物数量与动作，不承诺像素一致。可以重排纸面、改变画布比例、轻微融色并处理边缘；不能拉伸主体、任意重建建筑或补造场景。

## 输入与默认值

- source_image：原片；reference_image：可选，仅指导媒介与排版，不提供新物体。
- canvas_mode=portrait-paper，目标比例 3:5，来自示例的竖版纸面；source-ratio 可保持原比例，用户指定比例优先。
- edge_treatment=auto：按实际内容选择 architecture-etch / foliage-splash / water-drybrush，也可混合两种，以一个为主。
- paper_tone=warm-ivory：温暖象牙白或淡米色，细微纤维与颗粒。
- caption_mode=auto：一行 1–3 个词的英文情绪标题；用户可给精确标题或选择 none。
- season_policy=preserve-visible：保持原片可见植被色系、物候、天气和光向。已有拍摄季节信息直接复用；无法判断时按可见内容，不强制追问。

执行前简短说明实际采用的画幅、边缘和文字模式；用户指定原比例或无字时说明其选择，不再宣称使用竖版或小标题。无需为默认选择反复确认。若用户同时要求完全不重绘、完全无裁切且主体无法适配画幅，先说明冲突，再按其优先级处理。修改季节仅在用户明确要求时执行，并同步修改实际提示词的季节段落。

## 原片如何进入纸面

区分纸面画布与照片内容。默认用等比缩放、纸面留白和边缘遮罩适配 3:5；不是将横片直接拉成竖片，也不是通过生成新天空、水面或建筑填满画布。

主体群整体放在中上部或中部；有标题时底部留出标题空间，无字时只保留自然纸面留白。通常纸面可见约 20%–40%，但主体完整性优先，不用比例硬裁物体。保留画面内重要人物、地标、树干、岸线及有意义的倒影；边缘可以淡出非关键天空、地面、水面和枝叶末端。极宽原片允许形成横向场景岛嵌在竖纸中，无须强行填满页面。

核心区保持镜头记录般的细节、明暗、材质和自然深度；过渡带才逐步概括为画笔。避免全图等量水彩化。暖色主要来自纸底，不将蓝天漂成棕色或把绿叶改为秋叶。

## 边缘模式

| 原片特征 | 处理方式 | 必须保留 |
| --- | --- | --- |
| 建筑、清晰几何、天空 | architecture-etch：外围有断续细线、少量排线，天空与倒影局部色块擦印；部分结构由照片过渡到线稿 | 建筑轮廓、透视与比例；不能画虚构建筑延伸 |
| 树林、草地、斜向阳光 | foliage-splash：叶簇式不规则色斑、轻微水渍、稀疏飞溅与宽窄变化的干刷；过渡顺着枝叶和草坡走向 | 树干、投影方向、主要植被布局；色斑不是新增树木 |
| 湖泊、岸线、倒影 | water-drybrush：沿水波方向横向断续刷痕、颗粒擦痕和少量露纸，倒影逐渐碎裂淡出 | 岸上物体与倒影对应，不能切断主要人物或水中主体 |

每种模式都使用不对称边缘与自然纸面缺口，不做统一椭圆羽化、硬矩形剪贴或四边等宽边框。飞溅局限于过渡带附近。水面装饰笔触优先取原片已有色相，示例中的鲜蓝笔刷不是所有照片必需的元素。

## 文字与纸感

自动标题只写中性的视觉或情绪短语，不虚构地点、日期、人物关系或拍摄故事。参考图中的 Reflections、Falling light、Stillness 是示例，不是固定标题。标题设在空白纸面，通常左下，颜色为深褐或石墨灰，使用小号打字机风格或克制衬线字体，字号约画布短边的 1.5%–2.5%。不再加副标题、长段说明、日期或签名。

用户给出精确文字时原样保留；无字模式完全省略标题。必要时使用可用的文本排版工具独立排字，遵循当前平台图像编辑工具规则。不能把错字、乱码当作复古效果。

纸纹细微、低对比，与颜料颗粒相容；无明显折痕、污渍、烧边或厚重做旧。纸感可以统一背景与过渡带，不能盖住主体细节。最多一条极淡短横线作为标题辅助，默认不加。

## 执行与验收

1. 查看原片，记录主体、观看方向、原比例、主要光向与可见季节。风格参考不作为原片替代品。
2. 依据上述默认值确定纸面画幅、边缘模式和标题，形成实际提示词。使用可用的图像编辑工具，以原片为编辑输入。原片只读，结果另存。
3. 如使用确定性遮罩或分层合成，仅保存实际存在的层；如果使用生成模型，明确是生成式编辑，不能声称所有核心像素未变。工具不足时交付设计与提示词并说明未生成，不以无效果图片冒充完成。
4. 对照原片查看全图和局部：核心仍像摄影、边缘有媒介过渡、主体关系正确、无新增人物、无主体变形、季节未漂移、文字准确、留白与纸底自然。画布变为竖版不代表验收失败，主体被拉伸或不必要裁掉才是问题。
5. 发现具体问题时最多两次针对性修订；仍未满足时记录差异，不宣称通过。按 delivery-contract 的本分支条目交付。

没有用户指定的测试原片时，只完成技能文档，不把这些风格参考图或旧原片拿来测试，不把参考图写入 README 作为实测成品。
