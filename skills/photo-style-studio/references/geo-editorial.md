# Geo Editorial / 地理旅行志

## 目标与输入

摄影为主体，真实地图是辅助。优先级：原图完整性 > 地理真实性 > 主体可读性 > 编辑风格 > 装饰数量。

输入包括 source_image、可选 reference_image、location、location_precision（gps / landmark / neighborhood / city / unknown）。默认 map_mode=auto、preservation=strict。地点字段为空或仍为“填写城市”等占位文本时，按未知处理。

## 生成前选择地图位置

地图摆放位置 map_placement 初始为未选择，与地图类型 map_mode=auto 无关。不要默认右上角，也不要照搬参考图的位置。

若用户尚未指定位置，在生成地图图层或合成前询问并等待回答：

> 你希望地图放在照片的哪个位置？左上角、右上角、左下角、右下角、其他指定区域，或者让我根据照片构图自动推荐并安排？

可根据原片附上一句位置建议，但建议不等于用户已经选择。没有回答时不开始生成；可以继续检查原片和核实地理数据。

用户已经指定位置或明确表示“你来决定／自动安排”时直接复用，不重复询问。选择自动安排后，依据主体与负空间确定位置，无须再确认一次。方位按照片正常观看方向判断。

指定位置会遮挡主体时，优先在该区域内缩小、简化或微调地图；仍不适合时说明原因并建议替代区域，等待用户选择后再生成，不擅自换到另一个角落。在交付 manifest 中记录 map_placement_requested 与 map_placement_actual。

## 地点与数据

1. 明确标记的是拍摄者位置、被摄景点还是大致区域。已知桥梁的位置不能冒充摄影师位置。
2. 地点未知时询问，不依据画面猜出精确位置。城市名可用于城市范围地图，但不得把城市中心伪装成拍摄点。
3. 使用当前环境可用的可靠地图数据源，记录来源、检索日期、覆盖范围和许可。核实名称与几何匹配；不要把风格参考中的线条当作测绘数据。
4. 城市优先主要街道、水系与街区；海滨优先海岸线、岛屿和河口；山区仅使用有来源的地形、等高线或记录步道。城市级地点不足以确定照片中的山峰，不能绘制其所谓真实局部等高线。
5. 精确已知位置使用小红点。区域级位置用小红点加淡范围圈和 `Approx. area`；说明点是区域示意，范围圈也不代表测量误差。区域范围无法合理表达时只给区域名称，说明为何省略点。
6. 缺少地形数据时可以降级为已验证的更广域水系或区域轮廓，不编造曲线。没有任何可靠数据时暂停真实地图交付，说明缺失条件。

## 构图与视觉

- 首先识别主体与负空间。桥索、树枝、山脊等细结构同样受保护；“天空”不自动等于空白。
- 地图整体布局范围建议占画面 15%–25%，不是线条非透明像素的占比。负空间不足时缩小、简化或省略地图，不覆盖主体硬凑比例。
- 不添加矩形底板、卡片边框或大标题。用透明背景和外围渐隐融入画面，保持核心地理形态可辨。
- 保持地图几何比例，不能分别拉伸横纵轴或随意弯曲海岸线。叠图是独立示意，不声称与摄影透视配准。
- 使用细线、低饱和暖灰、灰白或石墨色，随背景调节可读性。起始线宽可取短边的 0.04%–0.09%，以全尺寸预览修正。透明度按背景调整，不机械套用固定数值。
- 英文地名建议 2–4 个，采用已核实拼写，文字独立排版。红色仅强调位置。
- 默认省略比例尺和指北针。仅当投影、地图方向、最终缩放以及距离计算均可验证时添加；地图旋转后同步调整指北针。
- 纸张印刷质感只作用于新增图层。不能对整张原片加颗粒、雾、全局纸纹或调色。用户明确要求改变原片时记录为独立的非 strict 版本。

## 合成

原片只读 → 地图数据矢量化/制图 → 地图透明层 → 标签层 → 位置标记层 → 可选局部纹理层 → alpha 合成。

使用普通制图和合成工具，不把整张原片交给生成模型重新绘制。地图可保存 SVG 中间件，再渲染为原片同尺寸 PNG。独立标签避免生成模型产生伪文字。

按 EXIF orientation 确定观看方向，以规范化后的解码图像作为像素基准；保持源文件不变。保留或明确转换 ICC 色彩配置，记录任何转换。地图与原片合成前统一工作色彩空间，避免静默色偏。若发生色彩转换，像素比较基准也必须经过同一转换，比较的是同一工作色彩空间中的像素。

如果最终省略全部地图，只能交付原片或构图建议并注明地图要求尚未满足，不能宣称地理旅行志成品已完成。

通过遮罩避让主体，只修改新增图层的 alpha，不能擦除或修补原片。合并透明叠层后在 alpha=0 的区域验证成品与基准解码图的像素相同；JPEG 重编码不能用于这个检查。

## 调度用任务摘要

执行下面摘要前，必须完成上述地图位置选择；没有选择或自动安排授权时不能直接生成。

> 对指定原片执行 strict 地理旅行志分支。先确认地点精度和标记含义，取得可追溯地图数据，选择适合负空间的地图类型。保持原片锁定，以独立透明图层合成细线地图、少量英文地名及精度适当的红色标记。地图布局以 15%–25% 为参考，主体保护优先。纸感仅施加于叠层。不虚构地形、坐标或比例尺。按交付规范导出并验证，能力不足时报告真实缺口。
