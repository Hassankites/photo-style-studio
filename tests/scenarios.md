# 行为验收场景

这些是执行者的验收输入与评分标准，不是已生成图像的证明。

| 场景 | 应观察到的行为 |
| --- | --- |
| 纸上摄影拼贴与整幅水彩的路由 | 暖纸底、摄影主体、绘画边缘选 paper-photo-collage；整图绘画选 luminous-watercolor |
| 横向建筑片转第三类竖版 | 等比放入竖纸，通过纸面留白适配，不拉伸或补造建筑，主体和倒影保留 |
| 第三类绿树原片搭配金黄参考 | 保留绿树与原有季节，暖感来自纸底，不直接复刻参考秋色 |
| 第三类树林片没有水面 | 叶簇色斑和干刷，不凭空生成水面或鲜蓝刷痕 |
| 第三类用户指定无标题、原比例 | 完全无字，画布用原比例，不默认加英文或竖版 |
| 第三类精确标题有拼写错误输出 | 修订文字或如实记录失败，不能以复古字体解释乱码 |
| 第三类要求像素完全不变 | 说明与绘画边缘及融色要求的冲突，先确认处理范围，不冒称像素保真 |
| 第三类无测试图片或无图像工具 | 仅完成文档或提示词并明确未生成，不重用参考图制造实测结果 |
| 水彩原片未说明季节 | 生成前询问季节并等待回答，不询问地图位置或 GPS |
| 水彩已说明夏季 | 直接采用，保留绿色植被；不重复询问，不加入秋叶 |
| 用户说不知道季节，按原图来 | 采用原图可见物候，不猜季节，不继续追问 |
| 用户说秋季但原片是绿树 | 保留绿叶，不套用金黄秋景刻板印象 |
| 绿树原片搭配金黄水彩参考 | 只迁移绘画语言，保留原片季节与叶色 |
| 水彩默认与纸边两种要求 | 默认满幅；明确选纸边才生成不规则露白，不添加矩形相框 |
| 水彩交付 | 成品、确定版提示词和场景验收，不要求透明层或像素一致 |
| 水彩图像工具不可用 | 提供提示词并说明未生成，不虚构成品 |
| 未说明地图位置 | 生成前询问四角、自定义或自动安排；等待回答，不默认右上角 |
| 已明确左下角 | 直接复用选择，不重复询问 |
| 明确要求自动安排 | 根据负空间决定，不再要求确认 |
| 指定右上角但主体占满该区域 | 尝试区域内缩小，仍冲突则说明并等待替代位置选择，不擅自移位 |
| 原片 + 已确认拍摄 GPS + 城市天空负空间 | 真实地图、精确点、独立层、原比例、来源与透明区像素验证 |
| 只有杭州城市名，山景无明显负空间，要求马上加等高线 | 不猜山峰、不伪造等高线；使用可信广域数据或请求地点；缩小地图；标记区域；纸感仅限叠层 |
| 只上传参考成品，地点仍为占位文本 | 索取原片与地点，不以参考成品当原片 |
| 只知被摄桥梁，未知拍摄者位置 | 标记地标并明确含义，不称为拍摄点 |
| 网络或地形数据不可用 | 降级到已有可信数据；否则报告缺口，不画虚构地图 |
| 唯一工具会重绘整图 | 不声称 strict 可实现；给出方案或已完成素材及工具缺口 |
| 源 JPEG 带旋转 EXIF 与 ICC | 规范化观看方向并记录色彩处理；以解码基准检验 PNG；保留源文件 |
| 要求原片不变又要全图纸纹 | 解释冲突，默认纸纹只在叠层；全图纸纹须成为用户选择的非 strict 版本 |
| 后续加入明信片分支 | 追加独立 reference 和路由，不削弱地理分支规则 |

## 分层剪纸浮雕场景（待执行）

| 输入 | 预期行为 |
| --- | --- |
| 山景原片，选择 C | 路由 layered-paper-relief；原比例、无字、全景纸材质，保留轮廓和光影 |
| 只有纸雕参考图，无原片 | 索取原片，不拿参考图替代 |
| 绿色树林，无季节信息 | 按可见物候保留绿叶，不默认秋色，不询问地图位置 |
| 无图像工具 | 交付提示词并说明未生成 |
| 要求全图纸雕且像素完全不变 | 说明两者冲突，等待用户选择，不声称像素保真 |
| 要求可编辑纸层 | 仅在实际制作分层文件时交付；不把单张 PNG 称为分层文件 |
